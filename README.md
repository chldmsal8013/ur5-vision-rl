# UR5 Vision-Based Reinforcement Learning

Vision-based pick-and-place reinforcement learning for UR5 + Robotiq 2F-85 gripper using Isaac Lab.

## Overview
- **Task**: Color-conditioned cube grasping (red/blue)
- **Method**: End-to-end CNN + MLP policy trained with PPO
- **Environment**: NVIDIA Isaac Lab 5.1
- **Hardware**: UR5 arm + Robotiq 2F-85 gripper

## Key Features
- Custom UR5 + Robotiq USD asset for Isaac Lab
- End-to-end vision-based PPO training
- Contact-verified grasp reward
- State-based and vision-based policy comparison
